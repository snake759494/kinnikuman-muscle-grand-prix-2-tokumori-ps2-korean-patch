# 근육맨 머슬 그랑프리2 특상 PS2 한글패치

PS2 일본판 **근육맨 머슬 그랑프리2 특상(キン肉マン マッスルグランプリ2 特盛, SLPS-25881)**용 비공식 한국어 패치입니다. **메뉴·설명문·팁·커맨드 리스트·기술명·초인 이름·컬렉션(에피소드 456종)** 등 게임 문자열과, **타이틀 로고 아래 제목 띠·화면 제목·도움말 버튼·스테이지 이름·캐릭터 이름판·VS 화면 별명 문구** 등 그림 글자를 한국어로 바꿨습니다. PCSX2용 **16:9 와이드 패치**도 함께 배포합니다. 현재 배포판은 **v1.2 (2026-11-06)**입니다.

릴리즈 첨부 파일은 한글패치 **Kinnikuman_MGP2_Tokumori_PS2_KO_v1.2.xdelta**와 와이드 패치 **SLPS-25881_9395CBE2.pnach**입니다. 저장소에는 제작 소스와 한국어 번역만 공개합니다. 원본·완성 디스크 이미지, 추출한 게임 파일, 일본어 원문, 글꼴 파일, 외부 실행 파일은 포함하지 않습니다. GitHub가 자동으로 만드는 Source code ZIP/TAR는 저장소 소스를 압축한 것이며 게임 파일이 아닙니다.

## 게임 소개 및 대상 버전

『근육맨 머슬 그랑프리2 특상』은 반다이남코 게임스가 2008년에 낸 PS2용 3D 대전 격투 게임입니다(개발 AKI). 2007년 아케이드판 『머슬 그랑프리2』를 옮기고 캐릭터와 모드를 더했으며, 원작 만화의 초인들이 필살기로 싸웁니다.

이 패치는 **PS2 일본판 SLPS-25881의 DVD ISO**에만 적용됩니다. 파일 이름보다 아래 표의 크기와 해시가 일치하는지가 중요합니다.

## 패치 적용 방법

```powershell
Get-FileHash -Algorithm MD5 -LiteralPath '.\Kinnikuman - Muscle Grand Prix 2 - Tokumori (Japan).iso'
```

위 표와 다르면 적용을 중단하세요. CHD, CSO, 압축 이미지에는 적용할 수 없습니다.

### xdelta UI 사용

1. 릴리즈에서 `Kinnikuman_MGP2_Tokumori_PS2_KO_v1.2.xdelta`를 받습니다.
2. xdelta3 패치를 지원하는 도구에서 **Apply Patch** 기능을 엽니다.
3. **Patch**에는 xdelta 파일을, **Source File**에는 해시가 일치하는 원본 `.iso`를 선택합니다.
4. **Output File**에는 새 파일 이름을 지정합니다(예: `Kinnikuman MGP2 Tokumori (Korean).iso`).

xdelta는 호환성을 위해 압축·2차 압축·파일 경로 헤더 없이 만들었습니다. xdelta 자체는 [공식 프로젝트](https://github.com/jmacd/xdelta)를 참고하세요.

### 명령줄 사용

```powershell
.\xdelta3.exe -d -s '.\Kinnikuman - Muscle Grand Prix 2 - Tokumori (Japan).iso' '.\Kinnikuman_MGP2_Tokumori_PS2_KO_v1.2.xdelta' '.\Kinnikuman MGP2 Tokumori (Korean).iso'
```

원본판 세이브 스테이트는 쓰지 마세요. 메모리 카드 세이브는 원본판과 호환됩니다.

## 16:9 와이드 패치 사용법 (PCSX2 2.x)

`SLPS-25881_9395CBE2.pnach`는 **한글패치를 적용한 ISO 전용**입니다. 한글패치가 실행파일(ELF)의 문자열을 고쳐 게임 CRC가 `D5FDEBDC`에서 `9395CBE2`으로 바뀌므로, PCSX2에 내장된 원본판 와이드 패치는 자동으로 적용되지 않습니다. 이 파일은 그 내장 패치(El_Patas 제작)를 한글판 CRC에 맞춰 옮긴 것입니다. 패치가 고치는 코드(0x1C5DEC)는 한글패치가 건드리지 않습니다.

1. PCSX2에서 한글판 ISO를 한 번 부팅하고 종료합니다. 로그(도구 > 로그 창 보기)나 게임 목록 속성에서 CRC가 `9395CBE2`인지 확인합니다.
2. `SLPS-25881_9395CBE2.pnach`를 PCSX2 `patches` 폴더에 복사합니다. 파일 이름을 바꾸지 마세요.
   - 설치판 기본 위치: `문서\PCSX2\patches`
   - 포터블판: PCSX2 폴더 안의 `patches`
   - 정확한 위치는 설정 > 폴더에서 "패치" 항목으로 확인할 수 있습니다.
3. 게임 목록에서 이 게임을 우클릭하고 **속성 > 패치**를 엽니다. **Widescreen 16:9**에 체크합니다.
4. 같은 속성 창의 **그래픽 > 화면**에서 **화면비(Aspect Ratio)**를 **와이드스크린 (16:9)**으로 바꿉니다. pnach의 `gsaspectratio=16:9` 줄 때문에 패치를 켜면 화면비가 자동으로 바뀌기도 합니다.
5. 게임을 시작하면 화면 위에 "1개의 게임 패치가 활성화되었습니다"가 뜹니다. 대전 화면의 3D 시야가 좌우로 넓어집니다.

주의
- 원본 일본판 ISO에는 이 파일이 필요 없습니다. PCSX2 내장 와이드 패치를 그대로 켜면 됩니다.
- 3D 대전 화면만 보정됩니다. 타이틀·메뉴·캐릭터 선택·HUD 같은 2D 화면은 가로로 늘어나 보입니다.
- 패치가 목록에 없으면 파일 이름의 CRC(`9395CBE2`)와 실제 게임 CRC가 같은지, `patches` 폴더 위치가 맞는지 확인하세요.
- 와이드 패치를 끄려면 속성 > 패치에서 체크를 풀고 화면비를 4:3으로 되돌립니다.

- 글꼴: 서울한강체 EB(원본의 굵은 명조체와 비슷한 글꼴), 그림 글자 일부에 나눔스퀘어 네오, 아주 작은 글자에 갈무리
- 원문 유지: 로고, 저작권 표기, 영문 UI 글자, 경기장 배경 현수막, 메뉴 선택 번쩍임 효과 그림, 캐릭터 선택판의 작은 "ランダム" 타일, 게임 아카이브의 보너스 게임(SLPM-53960)

## 알려진 한계

- 캐릭터 선택판 가운데의 작은 "ランダム" 타일은 이미지 구조가 특이해 원문으로 남겼습니다.
- 와이드 패치는 3D 화면만 보정하며, 2D 화면은 가로로 늘어납니다.
- PCSX2에서 주의 화면, 타이틀, 캐릭터·스테이지 선택, VS 화면, 대전 HUD, 일시정지 메뉴, 커맨드 리스트, 컨티뉴 팁, 토너먼트, 연습 모드 메뉴, 컨트롤러 설정, 옵션, 컬렉션, 게임 아카이브 확인창을 확인했습니다. 아케이드 엔딩과 승리·결과 화면, 실기에서의 동작은 확인하지 못했습니다. 문제가 있으면 이슈로 알려 주세요.
